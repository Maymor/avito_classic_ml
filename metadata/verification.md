# Что проверено перед передачей

Проверка выполнена 29 сентября 2026 года на Linux x86_64, Python 3.11.9,
с закреплёнными версиями библиотек и 8 потоками CPU.

`solution.ipynb` выполнен сверху вниз: 11 ячеек с кодом, без ошибок.
Он заново построил признаки, обучил модели для трёх временных блоков,
повторил значения v1/v2, затем обучил финальный ансамбль на всём train.
В notebook сохранены настоящие таблицы, график и результаты проверок.
HTML-предпросмотр открыт локально в браузере: проверены описание, таблица
сравнения, график и вывод контрольной суммы. На ширине 1280 и 800 пикселей
график и подписи читаются, результаты не потеряны. Внешние запросы браузера
были заблокированы; для этой проверки данные никуда не загружались.

Отдельно выполнен `run.py` с пустым новым каталогом результатов. Этот запуск
не использовал модели, признаки или промежуточные ответы из notebook.
Оба запуска создали CSV, побайтово совпадающий с отправленной v2:

```text

```

`verify.py` заново собрал все 472 признака только по тестовым событиям.
Их отпечаток совпал с обучающим запуском; четыре нативные модели восстановили
все 4 909 scores с точностью 1e-12. Проверены две колонки, исходный порядок
тестовых кук, отсутствие пропусков/дубликатов и диапазон score от 0 до 1.

Все 20 тестов прошли. Проверяются границы окон, будущие события,
перемешивание, точные дубликаты, пустая кука, агрегаты сессий/пагинации/курсора,
временные блоки, группировка равных scores, веса, параметры моделей и CSV.
Файл `metric.py` побайтово совпадает с выданным в задании.

Скрытый результат 0.82278 здесь не пересчитывался: он сообщён после отправки
на платформу, метки скрытого теста недоступны. Локальные временные блоки уже
участвовали в выборе решения, поэтому не названы независимым holdout.

Пакеты устанавливались только в виртуальное окружение. Исходные данные,
окружение и файлы обучения исключены из git. Никаких внешних публикаций
