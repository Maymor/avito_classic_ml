# Данные для запуска

Положите сюда три файла из задания, не меняя их содержимое:

```text
train.csv
test.csv
events.csv.gz
```

Они не входят в репозиторий и исключены через `.gitignore`. Можно оставить
их в другом месте и передать `--data-dir /путь/к/data` в `run.py` и `verify.py`.
В ноутбуке путь задаётся переменной `DATA_DIR` в первой ячейке с кодом.
Распаковывать `events.csv.gz` не нужно.
